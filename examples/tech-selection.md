# Example: Technology Selection

Use ClashCode to evaluate competing technologies.

## Run

```
> /consensus Should we use Rust, Go, or TypeScript for our new CLI tool? Team has 3 TypeScript experts and 1 Go developer. Timeline is 3 months.
```

The personas will:
- Pragmatist: weigh team skills vs language benefits
- Performance-extremist: benchmark expectations
- Future-architect: consider ecosystem and hiring
- Devil's advocate: challenge the premise

Result: a scored consensus with concrete reasoning.
